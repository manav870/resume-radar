How it works

A simple flow that does the heavy lifting behind the scenes.

1

Prepare Your Files

Create a Google Drive folder and add student assignments as text files. Name them like 27_Mohan.txt so the system auto-detects the roll number and student name.

2

Share with Service Account

Share both the input folder and a blank output Google Doc with the service account email (hackathon@hackathon-509406.iam.gserviceaccount.com) as Editor.

3

Enter IDs & Process

Go to the Grade page, paste the Folder ID and Doc ID, set the batch size, and click "Generate Batch Feedback".

4

Review in Google Docs

Open your feedback Google Doc. Each student's evaluation includes criterion scores, error analysis with corrections, hidden assumptions, and an actionable next step.

What the feedback looks like

Each student gets a structured diagnostic report with these sections:

Criterion Breakdown

Four dimensions scored out of 5: Clarity & Structure, Factual Accuracy, Completeness, and Conceptual Depth — each with a detailed diagnostic.

Error Analysis

Specific mistakes identified with what was written, why it's incorrect, and the correct approach — so students learn from their errors.

Hidden Assumptions

Unstated premises the student relied on, plus alternative approaches they may have overlooked.

Actionable Next Step

A core principle to review and a single targeted practice task designed to close the specific knowledge gap.
